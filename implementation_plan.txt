视频宠物识别系统 - 产品化实施计划
====================================

项目概述
--------
基于现有的YOLO视频处理脚本，构建一个完整的Web应用，实现从视频上传、数据标注、模型训练到视频处理的全流程管理。

技术栈选型
----------
前端：
- Vue 3 (已有基础) + TypeScript
- UI框架：DaisyUI + Tailwind CSS (已集成)
- HTTP客户端：Axios
- WebSocket：原生 WebSocket API
- 文件上传：Vue + Axios (支持大文件分片上传)
- 状态管理：Pinia (如需要)

后端：
- FastAPI (Python 3.10+)
- Celery (异步任务队列)
- Redis (任务中间件 + 消息订阅发布)
- WebSocket (FastAPI原生支持)
- SQLite/PostgreSQL (项目数据存储)
- Uvicorn (ASGI服务器)

关键技术实现要点
===============

1. 异步任务处理流程
   前端 → FastAPI (返回task_id) → Celery执行任务
   ↓
   任务进度 → Redis Pub/Sub → WebSocket → 前端实时更新

2. WebSocket连接管理
   - 使用ConnectionManager管理多个WebSocket连接
   - 按task_id订阅对应的Redis频道
   - 自动重连机制

3. 文件上传策略
   - 使用分片上传处理大文件（>100MB）
   - 前端计算文件MD5用于断点续传
   - 后端合并分片并验证完整性

4. 数据库设计
   主要表：
   - projects（项目）
   - videos（视频文件）
   - frames（提取的帧）
   - labels（标注数据）
   - training_jobs（训练任务）
   - inference_jobs（推理任务）
   - models（训练好的模型）
