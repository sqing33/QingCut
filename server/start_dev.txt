视频宠物识别系统 - 开发服务器启动指南
====================================

环境准备
--------
1. 确保已安装Python 3.10+
2. 确保已安装Redis服务器（用于Celery任务队列）

快速启动步骤
-----------

1. 安装依赖包
   cd server
   pip install -r requirements.txt

2. 启动Redis服务器（如果未运行）
   Windows: 
   - 下载Redis for Windows或使用WSL
   - 或使用Docker: docker run -d -p 6379:6379 redis

   Linux/Mac:
   redis-server

3. 启动FastAPI开发服务器
   cd server
   python -m app.main
   
   或使用uvicorn命令:
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

4. 访问API文档
   浏览器打开: http://localhost:8000/docs
   这里可以查看所有API接口并进行测试

5. 健康检查
   访问: http://localhost:8000/health
   应该返回: {"status": "healthy"}

API测试示例
-----------

创建项目:
POST http://localhost:8000/api/projects/
{
  "name": "我的第一个项目",
  "description": "测试项目描述"
}

获取项目列表:
GET http://localhost:8000/api/projects/

上传视频:
POST http://localhost:8000/api/1/videos
(使用form-data，字段名为file，选择视频文件)

获取视频列表:
GET http://localhost:8000/api/1/videos

常见问题
--------
Q: 导入错误（Pylance Error）
A: 这些是IDE的提示，实际运行前需要先安装依赖包。
   运行 pip install -r requirements.txt 后即可解决。

Q: 数据库文件在哪里？
A: 数据库文件位于 server/data/app.db，首次启动时自动创建。

Q: 如何重置数据库？
A: 删除 server/data/app.db 文件，重启服务器即可自动创建新数据库。

Q: 视频文件保存在哪里？
A: 每个项目的文件保存在 server/data/projects/{project_id}/ 目录下。

注意事项
--------
- 确保有足够的磁盘空间存储视频文件
- 开发环境下已配置CORS允许前端访问
- 生产环境部署时需要修改配置文件中的安全设置
